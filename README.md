# Bitcoin Sentiment vs Trader Performance

##  Overview
This project analyzes how **market sentiment (Fear vs Greed)** affects **trader performance** using historical trading data.

---

## Datasets
- Bitcoin Fear & Greed Index  
- Historical Trader Data (trades, PnL, size, side)

---

## Process
- Cleaned and standardized data  
- Converted timestamps to date format  
- Merged datasets on date  

---

## Analysis
- Profitability (average & total PnL)  
- Win rate  
- Trade size (used as risk proxy)  
- Buy/Sell behavior  
- Risk efficiency (PnL per trade size)  

---

## Key Insights
- Traders take **higher risk during Greed** (larger trade sizes)  
- Profitability varies with sentiment  
- Losses can be significant during volatile phases  
- Trading behavior changes based on market mood  

---

## Tools
Python, Pandas, Matplotlib, Seaborn, Google Colab
